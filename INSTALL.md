# Install

**Use the website:** https://epictechai.github.io/epic-tech-ai-agent/

## Windows (2 clicks)
1. Download: https://github.com/epictechai/epic-tech-ai-agent/releases/download/windows-latest/DO_EVERYTHING.bat  
2. Double-click the file  

First time only: install [Node.js LTS](https://nodejs.org) if `node -v` fails.  
API key: login window, or https://epictechai.github.io/epic-tech-ai-agent/keys.html  

## Mac / Linux
Use the Mac / Linux button on the website (copy → paste in Terminal).
