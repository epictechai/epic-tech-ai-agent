Get API keys through Slack

Prefer a human path? Join the Epic Tech AI Slack — we’ll help you get model access configured for local install.

How it works

  1. Join Slack with the button below
  2. Post in #api-keys (or DM the team)
  3. Say you’re installing Epic Tech AI locally and need key help
  4. We guide you to create a provider key in your account, or assist per our access policy
  5. You run opencode auth login on your machine — keys stay on your PC
Join Slack — request keys Or email epictechai@gmail.com
Security: Never paste live API keys in public Slack channels or GitHub issues. Use DMs only if we ask — or better, create the key yourself while we screen-share/guide. If a key was ever exposed, revoke it immediately.

Already have a key?

  1. Skip Slack
  2. Install via home → Install
  3. Run opencode auth login and paste the key only in that terminal

What we can help with

  • Which provider to pick (OpenAI, etc.) for local Epic
  • Creating a key in the provider dashboard
  • Windows baseline OpenCode + auth issues
  • Billing / credits questions at a high level
