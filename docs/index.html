Quick answers

Is this a website chatbot?

No. This site is the front door. The product installs and runs on your computer so you stay in control.

What do I need before the two clicks?

Windows: free Node.js LTS once (nodejs.org). Mac/Linux: Terminal. Everyone: an API key (get your own, or ask us on Slack).

Windows says the download is unsafe

Normal for new publishers. Click More info → Run anyway, or right-click the file → Properties → Unblock → OK, then double-click again.

Where do I put my API key?

Only in the opencode auth login window on your PC — never in email, public Slack, or chat with strangers. If you need a key, use Get keys via Slack and we’ll guide you safely.
