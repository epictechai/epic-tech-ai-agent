Install the agent on your computer

This website does not run the AI in your browser. It gives you a clear local install. The agent runs on your machine with your API key.

You need 3 things: (1) Node.js LTS  ·  (2) an API key (OpenAI or other)  ·  (3) the installer below

Windows — one file

Download DO_EVERYTHING.bat Get Node.js LTS
  1. Install Node.js LTS from nodejs.org → restart Command Prompt → check: node -v
  2. Download DO_EVERYTHING.bat (if Windows blocks it: Properties → Unblock, or “More info” → Run anyway)
  3. Put it in a folder, e.g. C:\Users\YOU\EpicTechAI
  4. Double-click DO_EVERYTHING.bat
  5. When asked, run opencode auth login and paste your API key only in that window
  6. Wait for SUCCESS — http://127.0.0.1:4097/ and keep the black window open

Later: run LAUNCH.bat in the installed folder, or RUN_TUI.bat for terminal-only.

macOS / Linux — one command

  1. Install OpenCode and Node if needed
  2. Run:
git clone https://github.com/epictechai/epic-tech-ai-agent.git
cd epic-tech-ai-agent
chmod +x LAUNCH.sh scripts/*.sh
opencode auth login
./LAUNCH.sh
Open repo

Requirements (every OS)

  • Node.js 18+ (LTS recommended) — nodejs.org
  • OpenCode CLI — installer installs the Windows baseline build for you; Mac/Linux: opencode.ai/docs
  • Model API key — OpenAI or another provider OpenCode supports. Never commit keys. Never paste keys into chat.
  • Disk + network — first run downloads the repo and npm packages

Troubleshooting

“Not compatible with the version of Windows”

Use the baseline binary. Run INSTALL_OPENCODE_WINDOWS.bat or full DO_EVERYTHING.bat again. Check: opencode --version prints a version number.

Web UI never opens / “Waiting for server”

Read %TEMP%\epic-web-run.log. Use RUN_TUI.bat for terminal UI. Ensure nothing else blocks port 4097. Keep the installer window open.

Unexpected server error / no model

Run opencode auth login again. In the UI, pick a model your key can use (e.g. openai/gpt-4o). Confirm billing/credits on the provider.

Windows SmartScreen blocked the .bat

Right-click file → Properties → Unblock → OK. Or click More info → Run anyway. Or clone the repo with git and run windows\DO_EVERYTHING.bat.

Where are the files after install?

Default: C:\Users\YOURNAME\EpicTechAI\epic-tech-ai-agent. Launchers also copy to C:\Users\YOURNAME\EpicTechAI\.
