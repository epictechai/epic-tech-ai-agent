FAQ

Straight answers.

Does this website run the AI?

No. GitHub Pages is static. The agent runs locally after you install. That’s safer and under your control.

What do I need?

Node.js LTS, OpenCode (Windows installer handles the Win10 baseline binary), and an API key from OpenAI or another supported provider.

“Not compatible with Windows”?

Use DO_EVERYTHING.bat or INSTALL_OPENCODE_WINDOWS.bat — they install the baseline build. Then opencode --version should print a version.

Web UI won’t open?

Keep the console open. Try RUN_TUI.bat. Check %TEMP%\epic-web-run.log. Run opencode auth login again.

Can I get an API key through Epic Tech AI?

Yes. Join our Slack and post in #api-keys — we’ll help you set up provider access. You still run opencode auth login locally. Never paste live keys in public channels. Start here: Get keys via Slack.

Are my keys in the repo?

Never. We scan for secrets. Use local auth only. If you ever pasted a key in chat, revoke it.
