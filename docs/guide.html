Help

Get running with a couple of clicks. No developer account required on our site.

Go to install Get API keys (Slack)

Windows

  1. Once: install free Node.js LTS
  2. Click Download installer on the home page
  3. Double-click the file (Run anyway if Windows asks)
  4. Paste your API key only when the login window asks
  5. Use the app at http://127.0.0.1:4097/ — leave the black window open

Mac / Linux

  1. On the home page choose Mac / Linux
  2. Click Copy install commands
  3. Paste into Terminal → Enter
  4. Complete key login when prompted

Stuck?

  • Slack — keys & support
  • Email epictechai@gmail.com
  • Windows “not compatible”: download installer again from home (includes the fix)
  • No browser UI: ask us on Slack for the terminal option
