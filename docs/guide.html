Local install guide

Clear path for any user · last updated 2026-07-26

The agent runs on your computer. The website only hosts docs and download links. You must provide a model API key. Keys are never stored in the git repo.

1. Prerequisites

  • Node.js 18+ LTS — nodejs.org → then node -v
  • Internet (first install downloads packages)
  • API key from OpenAI or another OpenCode-supported provider — or get help via Slack

2. Windows

  1. Download DO_EVERYTHING.bat
  2. Save to e.g. C:\Users\YOU\EpicTechAI
  3. Double-click (Unblock in Properties if SmartScreen blocks)
  4. Complete opencode auth login when prompted
  5. Open http://127.0.0.1:4097/ — leave the console window open

Installed app path (typical): C:\Users\YOU\EpicTechAI\epic-tech-ai-agent

3. macOS / Linux

git clone https://github.com/epictechai/epic-tech-ai-agent.git
cd epic-tech-ai-agent
chmod +x LAUNCH.sh scripts/*.sh
# install OpenCode: https://opencode.ai/docs
opencode auth login
./LAUNCH.sh

4. Verify

opencode --version
opencode auth list
# browser: http://127.0.0.1:4097/  or  RUN_TUI.bat / ./LAUNCH.sh tui

5. Daily use

  • Windows: LAUNCH.bat or RUN_TUI.bat
  • Mac/Linux: ./LAUNCH.sh
  • In UI: agent epic · try /anything hello

6. Troubleshooting

  • Not compatible with Windows → INSTALL_OPENCODE_WINDOWS.bat
  • Server error / no model → opencode auth login · pick a model your key supports
  • Web won’t start → RUN_TUI.bat · check %TEMP%\epic-web-run.log
  • Secrets → never commit .env · run npm run secret-scan in the repo
