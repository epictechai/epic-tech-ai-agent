User guide

Install · launch · commands · safety · last updated 26 July 2026

1. Requirements

  • OpenCode CLI on your PATH
  • A model provider configured (opencode providers or Machine/Kortix gateway)
  • Git, and optionally bun or npm for tool dependencies

2. Install & one-click launch

git clone https://github.com/epictechai/epic-tech-ai-agent.git
cd epic-tech-ai-agent
chmod +x LAUNCH.sh LAUNCH.command scripts/*.sh
./LAUNCH.sh                 # web UI, default agent: epic
# macOS Finder: double-click LAUNCH.command
# Windows: LAUNCH.bat or LAUNCH.ps1
# npm start                 # same as ./LAUNCH.sh

3. Health check

./LAUNCH.sh doctor
# expects: config OK, default agent epic, skills listed

4. Full-power commands

/anything <mission>     # full routing
/build /research /design /write /analyze
/legal /create /sell /site /ops /ship /supercharge
