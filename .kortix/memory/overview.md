## Purpose

Secure autonomous agent platform: SOTA multi-agent orchestration, Executor Gateway for third-party APIs (no key leakage), living project memory, and human-reviewed change requests to land work on `main`.

## Pitch

Agents that actually ship — code, research, ops, revenue plumbing — with auditability and restricted money paths.

## Shape

- Machine project (`kortix.toml`) + OpenCode runtime (`.kortix/opencode/`)
- Default primary agent: **`epic`** (alias: `kortix`)
- Specialists: `architect`, `builder`, `researcher`, `critic`, `ops`, `memory-reflector`
- Playbook skill: `epic-os`
- Slash commands: `/ship` `/build` `/review` `/research` `/ops` `/memory` `/supercharge`

## Stakeholders

- Owner brand: Epic Tech AI (`@EpicTechAI`)
- Humans merge all CRs; agents never self-merge

## Non-goals

- Agents inventing pricing or charging users without human-defined Checkout/pricing
- Secrets in git or memory
- Legacy product names (Smoke, Jarvis) in user-facing copy
